## Music

The root contains:

```text
music/
music/index.txt
```

Add MP3 files like:

```text
music/1.mp3
music/2.mp3
```

## Run

Open `index.html` directly, or for best music loading:

```bash
python3 -m http.server
```

Then open:

```text
http://localhost:8000
```
